# 连通候选二分排序验证报告

## 阶段结论

本阶段得到初步正面证据：与“逐条低分边直接删除”相比，先枚举内部连通且
每组至少2架的候选二分，再按跨组关系边得分排序，能够避免 `6+1+1` 式单机
碎片化。

预先在开发集选出的主规则为：

1. 使用完整360°空间的 `composite_min`；
2. 对每个候选二分计算所有跨组边分数的平均值；
3. 平均跨组边分数最低的候选排名第一。

主规则在开发集9个有效样本和严格留出集8个有效样本上，第一名均为离线局部
几何可行分组，共 `17/17`。这些第一名没有跨边平均分并列，因此结果不是由
无人机编号排序碰巧选中。

该结果允许继续验证真实 StarConvex 几何，但仍不足以接入 EGO-Planner 闭环。

## 数据集

### 开发集

- 柱体名义半径：`0.8 / 1.0 / 1.2 m`；
- 柱体横向偏置：`-1.0 / -0.5 / 0 / 0.5 / 1.0 m`；
- 每个构型41个纵向位置，步长 `0.2 m`；
- 15个构型、615个快照、6150条边记录；
- 面积采样分辨率 `0.15 m`。

### 留出集

留出集的半径和横向偏置均未出现在开发集中：

- 柱体名义半径：`0.9 / 1.1 m`；
- 柱体横向偏置：`-0.75 / -0.25 / 0.25 / 0.75 m`；
- 每个构型81个纵向位置，步长 `0.1 m`；
- 8个构型、648个快照、6480条边记录；
- 面积采样分辨率 `0.15 m`。

## 候选分组

所有无序二分均满足：

- 每个子群至少2架无人机；
- 两个子群在原始候选网格图的诱导子图中分别连通；
- 不指定四机对四机；
- 不指定上绕或下绕；
- 不使用无人机位置标签作为排序目标。

八机网格在这些约束下共有20种候选二分。

## 离线几何标签

对每架无人机计算前方 `±80°` 范围内的无碰撞平移方向，再取组内成员方向
集合的交集。一个候选二分只有在两个组分别存在至少一个共同方向时才记为局部
可行。

该标签不要求两个子群联合选路，也不检查子群间未来碰撞，因此只是局部几何
标签，不是完整轨迹规划真值。

## 排序结果

以 `0.5 m` 局部平移距离为主要标签：

| 分数 / 跨边目标 | 开发集 | 留出集 |
|---|---:|---:|
| 完整空间 / 平均跨边分 | 9/9 | 8/8 |
| 完整空间 / 最大跨边分 | 3/9 | 8/8 |
| 前方窗口 / 平均跨边分 | 3/9 | 8/8 |
| 前方窗口 / 最大跨边分 | 3/9 | 8/8 |

只有“完整空间 / 平均跨边分”在开发集和留出集上都保持一致。前方窗口在留出
集上表现良好，但在开发集的居中和整米偏置构型上容易把错误二分排在第一，
因此当前不能替代完整空间。

开发集中的分组会随柱体横向位置变化：

- 柱体居中时可产生 `4+4`；
- 柱体靠近上侧或下侧时可产生 `2+6`；
- 这说明分组成员由当前几何和关系分数产生，并非固定断开某条预设接缝。

## 标签尺度敏感性

开发集在 `0.3 / 0.5 / 0.7 m` 三种平移距离下都有9个有效样本，主规则均
为9/9。留出集在 `0.5 / 0.7 m` 下有8个有效样本，主规则均为8/8；在
`0.3 m` 下没有“完整编队局部受阻”的样本。

这说明“是否受阻”依赖评价距离。当前不能把 `0.5 m` 直接当成在线预测距离
或控制参数，它只是离线标签的观察尺度。

## 仍然存在的限制

1. 星形自由空间仍是二维96射线圆柱解析原型，不是 StarConvex 的三维点云、
   球面翻转和 QuickHull 网格；
2. 分数和标签虽然使用不同计算方式，但共享同一个精确圆柱模型，可能高估
   相关性；
3. 有效受阻样本总数只有17个；
4. 筛选分辨率为 `0.15 m`，还没有用 `0.10 m` 复核关键构型；
5. 只验证了单个静态柱体和理想刚性编队快照；
6. 没有测量噪声、点云遮挡、时间连续性、分裂滞回或合并；
7. 两子群分别有方向不代表它们能联合规划且互不碰撞；
8. 尚未接入 ROS，也没有修改 EGO-Planner。

## 下一门槛

下一步应在相同快照上引入 StarConvex 原项目的真实三维自由空间构造，并比较：

- 候选二分排名第一是否保持；
- 简化二维分数与真实三维分数的相关性；
- 开发集和留出集上的主规则是否仍稳定；
- 关键构型在 `0.10 m` 分辨率下能否复现。

只有这一步通过，才进入不控制无人机的 ROS 影子模式。
