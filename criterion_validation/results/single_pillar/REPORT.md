# 单柱体当前状态判据验证报告

## 结论

本实验尚不能证明“自由空间重叠度 + 可见性”足以直接驱动八机编队分裂。
当前结果只支持以下较弱结论：

1. 完整空间和前方窗口两种分数都会在柱体分隔候选关系边时显著下降；
2. 前方窗口能减少高阈值下由身后空间造成的持续低重叠；
3. 两机完整连线可见性仍然主导综合分数，因此前方窗口不能独自解决延迟合并；
4. 对网格关系图逐条删除低分边会产生 `6+1+1` 等碎片化分组，而不是自然
   产生两个内部连贯的子群；
5. 当前单柱体刚性直线扫描只有一个“尚未碰撞但完整编队局部不可行”的样本，
   不足以选择可靠阈值。

因此，本结果不应接入 EGO-Planner 闭环控制。

## 实验边界

- 八机 `2 x 4` 矩形编队；
- 一个名义半径 `1.0 m` 的柱体；
- 障碍膨胀 `0.35 m`；
- 编队中心沿 `x=-6 m` 到 `x=6 m` 扫描，步长 `0.2 m`；
- 61个静态位置，10条候选边，共610条原始边记录；
- 判据只使用当前状态，预测时间窗为0；
- 星形空间是二维96射线解析原型，不是 StarConvex 项目的三维
  QuickHull 实现。

前方窗口以每对无人机中点为原点，沿目标方向 `+x`，长度 `3.0 m`，横向
半宽 `2.0 m`。这些参数只是首轮对照参数，不是标定结果。

## 独立标签

离线标签检查一个刚性群组能否在前方 `±80°` 内整体平移 `0.5 m`，且所有
成员的扫掠线段都不进入膨胀柱体。该标签不反馈给分数计算，也不参与控制。

它只判断每个子群分别具有局部方向，不判断多个子群的联合路径分配和子群间
碰撞，因此不能作为完整轨迹可行性的证明。

## 数值结果

61个位置中：

- 43个位置的完整编队具有共同局部前向方向；
- 17个位置至少有一架无人机已经进入膨胀柱体；
- 1个位置在尚未碰撞时完整编队缺少共同局部前向方向，编队中心约为
  `x=-1.8 m`。

关键位置的最低综合分数：

| 编队中心 x | 完整空间 | 前方窗口 |
|---:|---:|---:|
| -2.2 | 0.3503 | 0.3560 |
| -2.0 | 0.3368 | 0.2909 |
| -1.8 | 0.0000 | 0.0000 |
|  1.8 | 0.0000 | 0.0000 |
|  2.0 | 0.3368 | 0.4500 |
|  2.2 | 0.3503 | 0.4500 |

前方窗口在越过柱体后恢复得更高，但 `x=1.8 m` 时两机连线仍被柱体阻挡，
可见性权重为0，两个综合分数都为0。

在唯一的无碰撞局部受阻位置 `x=-1.8 m`：

- 完整空间在阈值0.45开始产生局部有用分割；
- 前方窗口在阈值0.50开始产生局部有用分割；
- 两者首先得到的都是
  `[[0,3,4,5,6,7],[1],[2]]`，即 `6+1+1`；
- 主群有81个离散可行方向，两个单机各有13个，但这不是期望的编队子群结构。

阈值扫描没有选择最终阈值。完整空间在阈值0.90时会在43个仍可整体局部
运动的位置产生分割；前方窗口在相同阈值下降为5个。该对比说明前方空间过滤
值得继续研究，但不能修复图分割结构。

“完整编队可移动时仍分开”不直接等价于误分裂：如果合并要求两机重新可见，
暂时保持分开可能合理。该指标只用于显示局部运动标签与关系连通条件之间的差异。

## 下一实验门槛

在接入控制器之前，需要扩充离线样本，而不是继续调一个阈值：

1. 扫描多种柱体半径、编队横向偏置和局部平移距离，获得足够多的无碰撞
   受阻样本；
2. 对所有满足最小子群规模的候选二分方案进行枚举，检查低分边代价能否把
   “各子群分别有可行方向”的分区排在前面；
3. 比较完整空间与前方窗口在未用于调参的构型上的结果；
4. 只有分组结构和判据排序稳定后，才进入 ROS 影子模式。
